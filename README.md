# DINO AI 新課綱數學

<img src="icon.png" alt="DINO AI 新課綱數學" width="160">

國小到國中(一到九年級)數學的課程頁面,繁體中文與英文兩個版本。每個單元有閱讀、動畫、動手玩、遊戲、測驗、記錄六個分頁。純靜態網頁,語音使用預先錄製的音檔。

這份和「DINO AI 數學遊樂園」是不同的產品:遊樂園只開放遊戲,這份六個分頁全部開放。

## 內容

```
index.html          入口,自動轉到繁體版
icon.png            產品圖示(頁面的 favicon 也用這張)
start.bat           本機測試用(需要 Python)
zh/
  index.html        繁體中文版頁面
  audio/            音檔 97,123 個(約 1.33 GB)與索引 index.js
en/
  index.html        英文版頁面
  en-rules.js       英文讀音規則表(頁面播放時會用到,必須一起上傳)
  audio/            音檔 37,337 個(約 648 MB)與索引 index.js
docs/               英文數學讀音規則的說明
```

## 部署

1. 把整個資料夾原樣放到網站上,**保持目錄結構**。`zh/` 和 `en/` 必須在同一層,兩個版本的切換按鈕才會運作。
2. 用網址開啟,例如 `https://網域/路徑/index.html`。
3. **不要直接雙擊本機的 html 檔**:瀏覽器不允許本機頁面讀取同資料夾的音檔,語音會退回瀏覽器內建語音。這不是檔案錯誤。

本機測試:雙擊 `start.bat`,或在這個資料夾執行 `python -m http.server 8004` 後開啟 `http://localhost:8004/index.html`。

### 可能需要調整的地方

| 項目 | 位置 | 說明 |
|---|---|---|
| 語言切換的網址 | 兩個 `index.html` 裡的 `LANG_SWITCH_URL` 那一行 | 目前是 `../zh/index.html` 與 `../en/index.html`。切換時會帶著 `#單元-分頁`,所以會留在同一個單元 |
| 圖示 | `icon.png` | 兩個頁面的 `<head>` 以 `../icon.png` 引用 |
| 音檔路徑 | 頁面以相對路徑 `audio/檔名.mp3` 讀取 | 若音檔要放 CDN,需修改頁面裡組合網址的地方(搜尋 `'audio/'+`) |
| 索引檔的編碼 | `<script src="audio/index.js" charset="utf-8">` | 這個標籤在 `<meta charset>` 之前載入,`charset` 不能拿掉,否則中文對照鍵會變亂碼、全部退回瀏覽器語音 |

## 語音

- 老師與旁白:繁體版 Azure `zh-TW-HsiaoChenNeural`;英文版 Azure `en-US-SaraNeural`,語速 0.80。
- 動畫裡的學生台詞(男學生):繁體版 `zh-TW-YunJheNeural`(原音調);英文版 `en-US-BrandonNeural`,音調 +12%、語速 0.85。索引鍵是 `zhs|句段`、`ens|句子`,頁面播放學生台詞時先找這些鍵,找不到才用老師的音檔。
- 音檔已去除前後靜音。
- `audio/index.js` 會設定 `window.AUDIO_INDEX`,是「文字 → 音檔檔名」的對照表。
- 固定句子(課文、動畫台詞、題庫)是整句一個音檔;帶隨機數字的句子(動手玩的練習題、遊戲題目)由頁面把「文字片段」和「數字」的音檔依序播放拼起來。
- 找不到音檔的句子會退回瀏覽器內建語音。英文版會在瀏覽器主控台印出 `[沒有預錄音檔，改用瀏覽器語音]`,方便追查。
- 這個資料夾不含任何 API 金鑰,也不含錄音程式。

### 讀法

繁體版:

- 算式的括號會念出來,例如 (x − 3)² 念「括號 x 減 3 括號的平方」。座標 (h, k)、f(x) 與全形括號的補充說明不念。
- `%` 念「趴」。課文本來就寫成「百分之四十」的地方照原文念。
- 句子中間代表未知數的 `?` 念「多少」,例如「2 公尺 8 公分 = ? 公尺」。
- 直式分數(上下疊的寫法)念成分數,不會念成連在一起的數字。
- 「數」當動詞(數的時候、數一數、往後數、5 個一數)念 ㄕㄨˇ,當名詞(數字、小數、總數、倒數)念 ㄕㄨˋ。字幕注音和聲音用同一份片語表判斷。

英文版的讀法由 `en/en-rules.js` 決定(符號、單位、分數、日期、圖示名稱等)。要改某個讀法時改這個檔案,並重錄受影響的音檔;規則說明見 `docs/英文數學讀音規則.md`。

## iPhone / iPad

- 音檔與音效都用 Web Audio 播放。頁面會在使用者第一次觸碰畫面時建立並解鎖音訊通道(頁面裡標記為 `iOS-voice-fix-v2` 的區塊),之後由計時器接續播放的句子才會有聲音。
- 已設定 `navigator.audioSession.type='playback'`,讓靜音鍵打開時也能出聲;這個設定只有較新的 iOS 支援。
- **尚未在實機 iPhone / iPad 上測試。**

## 需要後端才能運作的功能

沒有。頁面原本是在 claude.ai 的 artifact 環境開發的,但課程頁沒有呼叫該環境的服務(頁面裡搜尋不到 `window.claude`),放在一般網站上就能完整運作。

## 會員與音檔保護

這是純靜態網站,登入只能做在前端,擋不住直接下載。任何人知道 `audio/` 底下的網址就能取得 mp3。若要保護內容,需由後端在登入後發放存取權(例如簽章網址)。頁面目前沒有登入功能。

## 資料儲存

學習記錄、測驗成績、錯題本都存在使用者瀏覽器的 `localStorage`,不會上傳。兩個語言版本放在同一個網域時,紀錄是共用的。

## 已知限制

1. **音檔沒有逐句人工試聽。** 讀音是依規則由程式判讀後合成的,已做程式比對與抽樣操作測試。
2. **隨機題目不是窮舉。** 動手玩的練習題與遊戲題目是隨機產生的。製作時以程式抽樣收集句子並補齊音檔(繁體版:固定文字 23,577 個句段、動手玩抽樣 11,445 句、遊戲抽樣 8,913 句;英文版:固定文字 28,705 句、動手玩抽樣 15,147 句、遊戲抽樣 11,918 句,檢查時都對得到音檔,繁體版動手玩只有 1 句答案是破折號的沒有),沒抽到的組合仍可能退回瀏覽器語音。
3. **拼接的接縫。** 帶數字的句子在數字前後會有輕微停頓。
4. **英文版沒有預錄的部分:** 開啟「中文翻譯」後顯示的中文、點英文單字查字義的發音。
5. **手機與平板尚未實機測試。**
6. **容量:** 音檔約 2 GB、13 萬多個檔案,上傳與部署需要時間。GitHub Pages 建議網站不超過 1 GB,這份超過了。
